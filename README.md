## MathTrainer – Пользовательский гид

**MathTrainer** – это бесплатный веб-тренажёр для отработки математических навыков.  
Вы решаете задачи, получаете обратную связь, смотрите свой прогресс и соревнуетесь с другими в таблице лидеров.

---

## 🎯 Основные возможности

| Функция | Описание |
|---------|----------|
| **Регистрация и профиль** | Личный кабинет для сохранения истории решений |
| **Выбор тем** | Алгебра, геометрия, уравнения (и другие) |
| **Уровни сложности** | Лёгкий, средний, сложный |
| **Интерактивные задачи** | Условия с формулами (KaTeX), поле для ввода ответа |
| **Мгновенная проверка** | После ответа – результат:  верно /  неверно + пояснение |
| **Прогресс и статистика** | Графики решённых задач, процент успеха, баллы |
| **Таблица лидеров** | Рейтинг пользователей по баллам |
| **Настройки** | Смена пароля, тёмная/светлая тема |

## 🚀 Как начать пользоваться

### 1. Регистрация
- Откройте сайт (например, `https://math-trainer.example.com`)
- Нажмите кнопку **«Зарегистрироваться»**
- Введите **email** и **пароль**
- После регистрации вы автоматически войдёте в систему

### 2. Вход
Если у вас уже есть аккаунт, нажмите **«Войти»** и введите свои данные.

### 3. Решение задач
- На главной странице выберите **тему** и **сложность**
- Появится карточка с задачей (математические формулы отображаются красиво)
- Введите ответ в текстовое поле
- Нажмите **«Проверить»**
- Сразу увидите результат:
  -  Правильно – получите баллы и появится кнопка «Следующая задача»
  -  Неправильно – покажется правильный ответ или подсказка

### 4. Прогресс и статистика
- Перейдите в раздел **«Статистика»**
- Выберите период (день / неделя / месяц)
- Вы увидите:
  - Количество решённых задач
  - Процент верных ответов
  - Распределение по темам (круговая диаграмма)
  - График прогресса по дням

### 5. Таблица лидеров
- Перейдите в раздел **«Рейтинг»**
- Там показаны топ-10 пользователей с наибольшим количеством баллов
- Ваше место подсвечено, если вы входите в топ

### 6. Настройки профиля
- В правом верхнем углу нажмите на аватар (или иконку пользователя)
- Выберите **«Настройки»**
- Можно:
  - Сменить пароль
  - Выбрать тёмную или светлую тему оформления
  - Включить/отключить уведомления (при желании)

##  Часто задаваемые вопросы (FAQ)

**Вопрос:** Нужно ли платить?  
**Ответ:** Нет, тренажёр полностью бесплатный (учебный проект).

**Вопрос:** Какие браузеры поддерживаются?  
**Ответ:** Последние версии Google Chrome, Mozilla Firefox, Safari, Microsoft Edge.

**Вопрос:** Можно ли пользоваться с телефона?  
**Ответ:** Да, сайт адаптирован под любые экраны (мобильные, планшеты).

**Вопрос:** Сохранится ли мой прогресс, если я выйду из аккаунта?  
**Ответ:** Да, все данные хранятся на сервере. При следующем входе статистика загрузится.

**Вопрос:** Что делать, если забыл пароль?  
**Ответ:** На странице входа нажмите «Забыли пароль?». Вам придёт письмо со ссылкой для сброса (функция появится в следующей версии).

**Вопрос:** Можно ли добавить свои задачи?  
**Ответ:** Пока нет, только встроенный каталог. В будущем возможна такая функция.

**Вопрос:** Почему формула отображается криво?  
**Ответ:** Убедитесь, что у вас включён JavaScript. В редких случаях помогает обновить страницу.

**Вопрос:** Кто создал этот тренажёр?  
**Ответ:** Студенты РТУ МИРЭА в рамках курса «Системная и программная инженерия».
